    Settings

    Wi-Fi

    Saving reboots the device. It will rejoin on the new network — you may need to reconnect to it. Also reachable at printdrop.local / printdrop via mDNS+LLMNR.

    Web UI Login

    Protects the whole UI + API with HTTP Basic. Stored as SHA-256 in NVS. Initial user/hash from platformio.ini PRINTDROP_AUTH_* or via serial auth <user> <pass>. Leave blank to keep current.

    Button long-press 5 s: factory reset (clears Wi-Fi + login). Serial: clear-auth / factory-reset.

    LED: idle 2 s blink, activity fast, error double-blink. Button short = eject, long = factory reset.

    About

    PrintDrop 0.1.0

    PrintDrop is a tiny ESP32-S3 bridge that exposes its SD card as a USB flash drive to your 3D printer while serving a fast, cable-free web UI over Wi-Fi — so you can drop a .gcode from your desk and print without ever walking a stick to the machine.
